## 先说人话：这套系统到底在干嘛

iWeaver 是一个 AI 工具站，靠 SEO 拉自然流量。这套自动化要解决一个问题：**让内容生产、发布、优化不用人手动一个个搞，而是定时跑、自动跑、有人盯就行**。

它干三件事：
1. **生产**：自动写 Agent 介绍页、博客文章、热点文章（AI 写，人审一遍）
2. **发布**：自动传到 WordPress、自动生成 TDK/封面图、提交 Google 收录
3. **优化**：定时看 GA/GSC 数据，哪个页跌了就自动改一版再发回去

另外还有两块**对外回复**的活也归你：邮件自动回复（EDM）+ 用户反馈自动回复（站内点踩点赞）。

## 这套东西靠什么跑

**一句话：一个 MCP 编排器 + 一堆适配器，定时触发，AI 写内容，WP 接收，飞书留痕，Superset 看数。**

| 模块 | 干嘛的 | 仓库位置 |
|---|---|---|
| **MCP orchestrator** | 总调度，跑各种"工作流" | `mcp-agentos/agentos_mcp_orchestrator_transfer/` |
| **wp_tes 适配器** | WordPress 内容生产（Agent 页、博客、热点、use case 图） | `mcp-agentos/.../adapters/wp_tes/` |
| **dashboard_metrics 适配器** | 采 GSC/GA4/Superset 指标，写进飞书表 | `mcp-agentos/.../adapters/dashboard_metrics/` |
| **competitor_seo 适配器** | 竞品调研 | `mcp-agentos/.../adapters/competitor_seo/` |
| **iweaver_admin 适配器** | 后台 Agent 上下线 | `mcp-agentos/.../adapters/iweaver_admin/` |
| **EDM 邮件回复** | 客服邮件自动应答 | `edm/edm-system/edm_service.py` |
| **反馈回复** | 站内点踩点赞自动回复 | `edm/edm-system/feedback_service.py` |
| **iWeaver 监控** | 每日报告、窗口告警 | `analytics/iweaver-monitoring/` |
| **多站点周报** | iWeaver/Palmly/LC 周指标面板 | `analytics/multisite-dashboard/` |
| **定时任务** | 全部 systemd timer | `infra/systemd/` |
